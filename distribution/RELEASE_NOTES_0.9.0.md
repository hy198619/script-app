# 草稿本 0.9.0 Public Beta 1

这是草稿本的第一个公开测试版本，适合临时记录、打磨微信或邮件草稿，以及保存几天后就不再需要的信息。

## 主要功能

- 打开即写，自动保存；
- `⌘↩︎` 划定草稿，新内容保持在最上方；
- 彩色标签、固定、复制和 Markdown；
- 全文搜索及标签筛选；
- 清理台、延期、存档和回收站；
- TXT、Markdown、完整 JSON 导出；
- 每日自动备份和完整备份恢复；
- 支持 Apple Silicon 与 Intel Mac。

## 下载哪个文件

下载 `Script-App-DraftBook-v0.9.0-macOS-unsigned.dmg`。`SHA256SUMS.txt` 用于核对安装包完整性。

## 安装前请注意

这个测试版本尚未使用 Apple Developer ID 签名，也没有经过 Apple 公证。macOS 第一次打开时会阻止运行。请先双击尝试打开，再进入 `系统设置 → 隐私与安全性`，点击“仍要打开”。

完整步骤见仓库中的[安装说明](https://github.com/hy198619/script-app/blob/main/docs/INSTALL.md)。请只从本仓库 Releases 下载。

系统要求：macOS 14 Sonoma 或更高版本。

草稿完全保存在本机，当前没有账号、分析统计或网络上传。数据尚未加密，请勿把它当作密码管理器。
