# 草稿本 0.9.0 Public Beta 1

DraftBook 是给一人公司主理人和内容创作者的草稿本，一个文字的临时中转站。

你可以用它记录那些临时的、或者还没到“正式归档”这一步的文字：一条需要即时记下的信息、突然冒出的灵感、边看视频边记下的笔记、需要反复打磨的微信消息、朋友圈文案或邮件、临时待办，以及稍后会用到的网址或账号名……

有些内容过两天就没用了；有些要在正式发出前改上几遍；还有一些只是先写下来，稍后再放进笔记软件或知识库。DraftBook 就是这样一个随手可写的地方，方便你迅速记下这些“短保”内容。它更像文字的临时中转站，不是另一个等着你整理和维护的知识库。

有些内容不值得单独建文件，或者暂时不知道该存在哪里。长期记在 DraftBook 里，也都没问题。

它不要求你为每段文字创建文件、标题或标签页。写完一条，按 `⌘↩︎` 把它划定为独立草稿，接着在同一页写另一个完全不相干的内容。

## 主要功能

- 打开即写，自动保存；
- `⌘↩︎` 划定草稿，新内容保持在最上方；
- 彩色标签、固定、复制和 Markdown；
- 全文搜索及标签筛选；
- 清理台、延期、存档和回收站；
- TXT、Markdown、完整 JSON 导出；
- 每日自动备份和完整备份恢复；
- 支持 Apple Silicon 与 Intel Mac。

## 下载哪个文件

下载 `Script-App-DraftBook-v0.9.0-macOS-unsigned.dmg`。`SHA256SUMS.txt` 用于核对安装包完整性。

## 安装前请注意

这个测试版本尚未使用 Apple Developer ID 签名，也没有经过 Apple 公证。macOS 第一次打开时会阻止运行。请先双击尝试打开，再进入 `系统设置 → 隐私与安全性`，点击“仍要打开”。

完整步骤见仓库中的[安装说明](https://github.com/hy198619/draftbook/blob/main/docs/INSTALL.md)。请只从本仓库 Releases 下载。

系统要求：macOS 14 Sonoma 或更高版本。

草稿完全保存在本机，当前没有账号、分析统计或网络上传。数据尚未加密，请勿把它当作密码管理器。
